# Project Rules for Vektor (.vk)

## HARD RULE: STRICT SINGLE-LANGUAGE POLICY
- **NO OTHER LANGUAGES OTHER THAN VK**: Never introduce Python (`.py`), JavaScript (`.js`), Node.js, Shell wrapper workarounds, or secondary scripting languages into Vektor projects unless explicitly requested by the user.
- **PURE VEKTOR PROMISE**: All application logic, CLI tools, bots, and scripts MUST be written natively and strictly in Vektor (`.vk`).
- **NO HIDDEN HELPERS**: Always ask and inform the user before adding any external system dependencies or toolchain primitives.
